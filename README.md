# arxiv-digest

Daily arXiv paper digest with Japanese summaries, generated by the news bot in
[mktk1117/claude-codes](https://github.com/mktk1117/claude-codes).

## Web page

**Open the site: https://mktk1117.github.io/arxiv-digest/**

## Contents

- `index.html` – archive browser (served by GitHub Pages)
- `paper.html` – per-paper summary page (`paper.html?id=<arxiv_id>`)
- `data/YYYY-MM.json` – monthly archive of digested papers
- `details/<arxiv_id>/` – `paper.json` summary plus chapter figures
- `figures/<date>/<arxiv_id>.jpg` – hero images
